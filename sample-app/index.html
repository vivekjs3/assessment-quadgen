Vivek Pod Platform Proj

GitOps-driven Kubernetes CI/CD Platform powered by Jenkins Configuration-as-Code (JCasC), KinD, and Ephemeral Agent Pods.

⚡

Ephemeral Build Pods

Build agents dynamically spin up on-demand as Kubernetes pods (`jnlp` + sidecars) and self-destruct immediately after build completion.

🔐

Zero-UI GitOps JCasC

100% of Jenkins configuration, RBAC matrix (Admin, Developer, Auditor), and Kubernetes credentials are seeded via Code with zero manual UI steps.

📦

Zero-Cost Registry

Integrates a local container registry on port 5001 linked directly with the KinD cluster for rapid image pushes and deployments.
